# 발표·면접 설명 가이드

## 3분 시연

1. **투자 관점 (20초)**: “일별 시장 민감도와 자산 간 위험으로 비중을 정합니다. 차트 신호보다 자산배분 과정을 검증하려고 했습니다.”
2. **설계 (40초)**: 설정과 `research/model.py`. “CAPM이 기대수익을 만들고 평균·분산이 비중을 정합니다. 집중도와 공매도·차입 제한을 적용했습니다.”
3. **성과 (50초)**: 보고서의 성과·낙폭·비용 표. “이 구간 CAPM 전략은 SPY·동일비중보다 뒤졌습니다. 모델을 추가했다는 사실만으로 성과가 개선되지는 않았습니다.”
4. **검증 (40초)**: `signals.csv` 신호일·체결일과 테스트. “종가 수익을 소급해 받지 않습니다. 비용 포함 원장과 미래 데이터 변조 테스트가 있습니다.”
5. **OMS (30초)**: `python -m oms.demo`. “중복 방지·응답 유실 후 대사·부분 체결은 별도 OMS로 시연합니다. 연구 원장과 실주문 연결은 남아 있습니다.”

## 설명할 수 있어야 할 질문

**CAPM과 평균·분산의 차이?** CAPM은 시장 위험으로 기대수익을 추정한다. 평균·분산은 기대수익·공분산을 받아 비중을 고른다.

**베타와 변동성의 차이?** 베타는 시장과 같이 움직이는 정도다. 변동성은 자체 수익률의 흔들림이다. 시장과 독립적인 흔들림은 베타와 다르다.

**변동성 낮은 ETF만 사면 안 되나?** 조합의 위험에는 공분산이 들어간다. 개별 순위만으로 판단할 수 없다. 최소분산 비교는 기대수익 추정의 추가 가치도 검증한다.

**왜 252일·λ=5·25%?** 첫 결과 전에 고정한 해석 가능한 실험 가정이다. 유일하게 옳거나 투자자의 실제 성향을 측정한 값은 아니다.

**매일 전부 사고파나?** 새 목표와 기존 보유분의 차이만 거래한다. 작은 변경도 거래하는 현재 방식은 비용에 취약할 수 있다. 월별·무거래 구간·회전율 벌점은 다음 실험이다.

**미래 참조를 어떻게 막았나?** t 종가까지의 자료로 판단하고 다음 거래일 종가에 체결한다. 미래 가격·금리 변조로 이전 신호·NAV 불변을 검사했다. 사후 데이터 수정 편향은 남는다.

**왜 비용에 방정식이 필요한가?** 비용 차감 전 자산을 전부 배분하면 매수 비용을 낼 현금이 부족하다. 차감 후 투자금과 거래금액을 함께 풀어 차입을 막는다.

**수익률이 낮으면 실패인가?** 이 결과는 초과수익을 입증하지 못했다. 위험·비용·추정 오차와 함께 그 사실을 설명해야 한다. 손실 구간이나 비교 전략을 숨기지 않는다.

**실거래 시스템인가?** 실제 가격 백테스트와 로컬 모의 OMS다. 증권사 연동과 연구용 조정수량을 실주문으로 바꾸는 작업은 남았다.

**아직 설명 못 하는 코드가 있다면?** 구현·도움받은 범위를 사실대로 밝히고 `config → estimate → optimize → simulate → metrics` 순서로 읽는다. 숫자가 나왔다는 사실과 모델 이해를 구분한다.
